## Capture instructions

- For desktop: use Chrome at ~1440px width, 100% browser zoom; capture the relevant page or visual section rather than a tiny unreadable entire long scroll.
- For mobile: press F12 -> Ctrl+Shift+M (device toolbar), choose a representative width such as 390px, and set a realistic portrait height (e.g. 844px). Better still, verify important screens on an actual phone.
- Use PNG or optimized WebP consistently; if changing the extension, update the paths in the root README.
- Remove browser developer tools, notifications, account details and sensitive information from screenshots.
- Use **demo names and dummy payment information only**; do not use real card information.
- Make images readable and keep file sizes reasonable. Rough targets: desktop ≤1–1.5 MB; mobile ≤400–700 KB per image, without sacrificing text clarity.
- **Add screenshot files before publishing the root README**, or its image references will be broken on GitHub.
